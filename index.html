Technologies

KiCad EDA

Open-source schematic design and board routing. Project porting and hardware cost optimization for seamless manufacturing.

Altium Designer

Schematic capture, multi-layer high-density PCB layout (HDI), component library management, and DFM-compliant manufacturing file generation (Gerber, BOM, Pick&Place).

Autodesk Fusion 360

Industrial enclosure design for electronics. Integrating Altium STEP models, modeling mechanical tolerances, snap-fits, and light pipes.

FreeCAD

Parametric open-source 3D modeling for mechanical components and enclosures. Creating solid models and preparing drawings under ISO standards.

STM32 Ecosystem

C/C++ firmware engineering utilizing STM32CubeMX and HAL/LL APIs. Peripheral configuration (DMA, ADC, TIM) and hardware power management.

nRF Controllers (Nordic)

Developing ultra-low power wireless applications on nRF52/nRF53 series. Implementing BLE (Bluetooth Low Energy) stacks and engineering with nRF Connect SDK (Zephyr RTOS).

ESP32 & Wireless

Developing connected devices using ESP-IDF and Arduino IDE. Configuring Wi-Fi/BLE stacks and integrating MQTT for telemetry streaming.

Node.js & TypeScript

Developing robust cloud backends for IoT platforms. Handling high-throughput MQTT broker data streams and designing scalable REST APIs.

React / JavaScript

Building responsive web dashboards for real-time telemetry visualization, chart rendering, and remote device configuration.

3D Printing & Prototyping

FDM/SLA rapid prototyping for physical form-factor validation and mechanical testing before injection molding.

Development Phases

1
Phase 1 (Project Kickoff)

Requirements Analysis & Technical Specs (TRS)
Responsibilities:
  • Gathering and formalizing client requirements for the target IoT product.
  • Analyzing electronic component markets considering current global stock availability.
  • Goal: Fixing system architecture, selecting core MCUs/sensors, and drafting the preliminary BOM.
  • Result: Approved technical specification document, minimizing late-stage hardware redesign risks.
Phase 2 (EDA Engineering)

Schematic Capture & PCB Layout (Hardware)
Responsibilities:
  • Designing electrical schematics and routing multi-layer PCBs in Altium Designer / KiCad.
  • Managing high-speed constraints, impedance control, and power distribution network (PDN) integrity.
  • Goal: Engineering reliable power stages, interface protection (ESD), and optimal space allocation.
  • Result: Finalized 3D board models and complete production-ready file package (Gerbers, BOM, Pick&Place).
2
3
Phase 3 (CAD Prototyping)

Enclosure Modeling & 3D Printing (Mechanical)
Responsibilities:
  • Importing Altium STEP models into Autodesk Fusion 360 / FreeCAD for precise physical integration.
  • Parametric design of custom enclosures, focusing on snap-fits, mounting bosses, buttons, and light pipes.
  • Goal: Validating form-factor ergonomics, tolerances, and mechanical fit before expensive mold tooling.
  • Result: FDM/SLA 3D-printed enclosure mockups for hands-on, real-world evaluation.
Phase 4 (MCU Programming)

Embedded Firmware Engineering (Firmware)
Responsibilities:
  • Developing low-level peripheral drivers in C/C++ (STM32 HAL/LL, ESP-IDF, nRF Connect SDK).
  • Deploying real-time operating systems (FreeRTOS / Zephyr) for critical task scheduling and thread safety.
  • Goal: Coding core business logic, ultra-low power states, and wireless stacks (Wi-Fi, BLE, MQTT).
  • Result: Stable, highly optimized, and maintainable modular firmware.
4
5
Phase 5 (Cloud & Web)

Cloud Infrastructure & Web Platform (Fullstack)
Responsibilities:
  • Building scalable backends (Node.js / TypeScript) to ingest and parse incoming MQTT telemetry streams.
  • Creating responsive frontends with React for live telemetry tracking, data rendering, and remote setup.
  • Goal: Establishing a seamless End-to-End connection between physical hardware and the cloud web app.
  • Result: Fully operational remote monitoring platform accessible securely from any browser.
Phase 6 (Lab Testing)

Assembly, Integration & Hardware Debugging
Responsibilities:
  • Hand-soldering and assembling the first physical prototype batches in a well-equipped laboratory.
  • Stress-testing the entire ecosystem (Hardware + Firmware + Cloud) under simulated field workloads.
  • Goal: Tracking down signal bugs using oscilloscopes/logic analyzers and resolving firmware memory leaks.
  • Result: A fully verified, field-tested physical prototype of the working electronic device.
6
7
Phase 7 (Final Release)

Design for Manufacturing & Production Prep (DFM)
Responsibilities:
  • Optimizing PCB layouts and creating alternate BOM lists to secure against global part shortages.
  • Preparing assembly blueprints, test fixtures, and guidelines for contract manufacturing assembly.
  • Goal: Minimizing assembly failure rates and decreasing per-unit manufacturing cost for mass production.
  • Result: The ‘Golden Sample’ of the product and complete factory-ready package release.
